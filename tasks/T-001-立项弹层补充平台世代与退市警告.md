## 描述

PRD FR-6 要求「在即将退市平台立项时，立项界面必须给出红字警告『该平台将于第 N 年退市』」。当前 `src/ui/modals.js` 的 `projectModal` 只展示平台名称、授权费与成本系数，玩家看不出平台所处的生命周期阶段，也不知道自己是否在往一个快要死掉的平台上砸钱。

范围：`src/ui/modals.js`（`projectModal` / `updateProjectEstimate`）、`styles/components.css`（警告与阶段标签样式）。数据一律从 `src/data/platforms.js` 的 `platformState` / `PHASE_LABEL` 读取，不在 UI 里复制一份年份表。

## 验收标准

- [ ] 平台下拉项文案包含当前阶段标签（上市 / 成长 / 巅峰 / 衰退）
- [ ] 选中处于衰退期的平台时，弹层出现红字「该平台将于第 N 年退市」
- [ ] 选中非衰退平台时该红字不出现，切换下拉即时更新
- [ ] 新增样式仅在 `components.css`，不影响既有配色与布局
- [ ] `node tests/run.mjs` 全绿
- [ ] 浏览器实测：项目弹层依次切换各平台，警告出现/消失与附录 A 年份一致
