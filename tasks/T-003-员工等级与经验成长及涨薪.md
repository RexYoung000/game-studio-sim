## 描述

PRD FR-5：「等级随累计贡献提升，等级提升涨薪」。`hireStaff` 已给员工写入 `level: 1` 与 `exp: 0`，但全项目没有任何地方累加或读取这两个字段，等级实际上是个死字段，玩家培养员工的唯一手段只剩花钱培训。

范围：`src/data/balance.js`（员工等级门槛表）、`src/systems/staff.js`（新增 `addStaffExp` / 升级判定）、`src/systems/project.js`（`tickProject` 中按产出累计经验）、`src/ui/staffPanel.js`（等级与经验进度展示）、`src/state.js`（如需要的默认值）。

## 验收标准

- [x] 员工参与开发时按当周实际贡献累计经验，休息/闲置周不涨经验
- [x] 经验达到门槛后升级，等级上限 5
- [x] 升级时薪水按固定比例上调，并写一条 staff 日志
- [x] 员工卡展示 `Lv.N` 与经验进度，满级显示「MAX」
- [x] 存档保留 `level` / `exp`，读档后继续累计
- [x] `node tests/run.mjs` 全绿，并新增用例覆盖「经验累积→升级→涨薪→满级封顶」
