## 描述

PRD FR-5：员工每 4 周结算薪水，「现金不足时先扣款失败，触发警告，累计两次破产」；§3 完成条件同样写的是「累计现金为负且无法支付薪水时提前破产」。当前 `src/systems/staff.js` 的 `paySalaries` 直接 `state.cash -= total` 把现金扣成负数，`src/systems/progression.js` 的 `checkEnd` 只要 `cash < 0` 立刻判破产——一次现金流断裂就游戏结束，和 PRD 不符，也把「差一点发不出工资」的紧张感做没了。

范围：`src/systems/staff.js`（`paySalaries`）、`src/systems/clock.js`（发薪步骤）、`src/systems/progression.js`（`checkEnd` 破产条件）、`src/state.js`（存档字段与旧档默认值）、`src/data/balance.js`（破产阈值常量）。

## 验收标准

- [ ] 存档新增 `salaryFailures` 计数，新档为 0，读档缺失时按 0 处理
- [ ] 现金不足以支付全额薪水时：不扣款、不产生负现金，`salaryFailures + 1` 并写 warn 日志与新闻
- [ ] 成功发薪后将 `salaryFailures` 归零
- [ ] `salaryFailures >= 2` 时进入破产结算，`endReason = bankrupt`，弹层显示「破产结算」
- [ ] 现金为负但 `salaryFailures < 2` 且能继续支付时，不提前结束
- [ ] `node tests/run.mjs` 全绿，并新增用例覆盖「一次欠薪不破产 / 两次欠薪破产」
